   results from separate frozen models. Preserved by unchanged source hashes; **not** revalidated

   equation anywhere in this work.

## Evidence classes and interface boundary

The intended system is coarse state → local and family/set feature construction →
physics-grounded wall closure → local-frame wall-on-fluid vector traction → declared
conditioning lift → conditional generator. The frozen closure export includes a Krank-specific
branch embedding derived from that target member's own wall-stress-free station set. Its
header contains neither branch-network weights nor set normalisation, so it cannot construct a new
source embedding. Archived deterministic training code and a standardised station bundle retain
the architecture, local rows, padded member sets, masks and targets, but no full-model checkpoint;
regenerating branch weights would therefore be a new fit rather than inference replay. The set's
fifth feature is fully defined as
\(\beta_p=\delta^\ast_{\rm res}(\partial_xp)/u_p^2\), with kinematic pressure,
\(u_p=(\nu|\partial_xp|)^{1/3}\), the same resolved
\(y_m\leq y\leq\delta_{99}\) displacement-thickness support as the fourth feature, sign carried
by \(\partial_xp\), and \(\beta_p=0\) at zero pressure gradient. Its available adapter also
replaces native pressure gradient and
resolved-region displacement thickness by different quantities. On the ten retained Krank
profiles those substitutions give pressure-gradient relative RMSE `0.961` (correlation `0.098`),
full/resolved thickness ratio `1.292–2.366`, and closure-output relative RMSE `0.408` with one
sign change. These are interface-sensitivity diagnostics, not transfer estimates. Source-valid runtime construction and
calibration-consistent local features remain unresolved for that archived path; it is superseded
by the grouped-protocol hill re-test and is retained only as an audit record.

- **Level 1** supplies a dense contemporaneous three-component velocity band derived from the
  target aligned-cube LES. Every supplied cell is excluded from scores.
- **Level 2** is the closure-conditioned composition, established on the cube, its reversed-time
  re-test, the channel slot and the separating hill's diffusion cell (see the status block
  above). The archived Case1 candidate is source-invalid and withdrawn; the archived hill
  scalar-proxy study is superseded by the grouped-protocol re-test.
- **Level 3** is companion closure-side evidence only and awaits an author-confirmed public
  citation.
- **Level 4**, solver-coupled WMLES, is absent.

The cube result supports bounded oracle wall-band sensitivity in one record. It does not support
closure composition, runtime causality, wall-location uniqueness, generative superiority or
deployed WMLES.

fields `(u,v,p)`. The local pipeline labelled it a wall jet/backward expansion, described the

correlation, sign, skin-friction, separation and cross-kind claims are invalid.

cellwise CRPS that excludes model-fit uncertainty. These do not change the fatal source finding.

## Cube data contact and statistics

The first-contact M0 result is a hash-pinned terminal aggregate, not independently replayable at
per-time level. Its member-level predictions are also unavailable, so the eight-sample mean is
conditional on the realised sampler draws and its Monte Carlo error cannot be replayed. M1/M2 are
development sensitivities on the same 160 targets. The maximum audited
integral time is 122.481730 native snapshots. The 98 omitted fields give count ratio 0.800; the
first evaluated state is 0.808 such times after the last training state. The 343-output evaluation
remainder has count ratio 2.800 and elapsed duration 2.792. Moving-block limits are conditional on
one finite record and fitted model, without multiplicity adjustment.
The two later continuation fields used only for the native-\(y^+\) audit are separated by
29.999793 convective-time units. This exceeds the historical signal-specific estimate
29.277608 but not the current conservative value 36.744519; machine-readable metadata therefore
sets the conservative-separation and temporal-independence flags to false.

M0 complete/near/farther aligned-arm fluctuation \(R^2\) is
`0.10308/0.24311/-0.04030`; complete aligned-minus-absent/far-time gains are
`0.17548/0.30688`. M2 lower-level arrays replay, but M2 is post-contact development evidence.
The fair farther-region energy score favours the aligned band. Component-spectrum and
instantaneous quadratic-profile diagnostics fail to beat both controls. The 51.4% plug-in interval
hit fraction is not a finite-ensemble calibration test.

The nominal interior comparator is quarantined because it scores its own observed shell.
Two deterministic direct-band seeds are positive over complete/near regions but differ in protocol
from M0. Nearest-training-band retrieval is strongly negative. These delimit attribution and do
not form a matched leaderboard.

## Reproduction and access boundary

`bash codes/reproduce_all.sh` verifies pinned sources, rebuilds five active main figures, two
Supplementary figures and one unmistakably source-invalid withdrawn diagnostic display, compiles
both PDFs, and replays the M2 and ensemble sufficient-statistic endpoints. The revision verifier
checks the reviewed source-first contract for headline and decision-bearing statements. Separately,
each plot producer compares actual Matplotlib data with source-derived expectations and emits one
record per semantic artist group; 42 groups span the eight displays. Adversarial mutations confirm
that a nearby wrong key, reversed contrast and malformed multidigit shape fail. This scoped
guarantee deliberately does not treat every typeset numeral as an empirical result. A separate
reader-consequence gate recomputes support geometry and the fair energy score from retained arrays,
checks absolute-versus-differential conclusions, adverse gates and temporal interpretation, and
extracts public PDF text to prevent historical machine labels from becoming physical claims. The
package also inspects all eight released displays at 180-mm publication
width, including text containment within rounded boxes and a one-point floor for plotted strokes
and axes spines. The compact release is dependency-closed for those
outputs. The raw cube volume, M0/M2 checkpoints, exact origin producers, final licence and DOI
still require author-approved reviewer/public access. cuDNN benchmarking and incomplete RNG-state
custody preclude bitwise retraining claims.

Legacy same-time-leaking hill derivatives remain quarantined. Negative farther-region absolute
skill, null physical corroboration, failed grouped-hill replication, failed scaling and all
source-invalid/adverse E2 values remain visible.
